## Этап 1. Ядро SPH (P0)

### 1.1 Единицы и давление
- **Проблема:** при `h = 16`, `m = 1` плотность ≈ 0.06 при `rest_density = 1.0`, давление всегда 0.
- **Действия:**
  - [ ] Ввести единый источник истины: `particle_spacing` (шаг начальной решётки).
  - [ ] Вычислять `rest_density` автоматически: ρ₀ = Σ m·W(rᵢⱼ) для частицы в идеальной решётке; или масса = ρ₀·spacing².
  - [ ] Связь: `h = 2…4 · spacing` (рекомендуется ~2).
  - [ ] Заменить линейное давление на Tait EOS: `p = B((ρ/ρ₀)^γ − 1)`, `γ = 7`, и разрешить небольшое отрицательное давление (или оставить `max(0)`, но осознанно).
  - [ ] Ограничение скорости звука `c` → `B = ρ₀c²/γ`.
  - [ ] Тест «гидростатика»: блок частиц оседает, `ρ_avg/ρ₀ ∈ [0.97, 1.03]`, `vmax` затухает.

### 1.2 Согласованность сил и массы
- **Проблема:** силы давления и вязкости уже в виде ускорения, а `integrate` делит на `mass` ещё раз.
- **Действия:**
  - [x] Решить: поле `force` хранит **силу** или **ускорение**; привести все три места (`forces.rs`, `integrate.rs`) к одному.
  - [x] Вязкость: формула `μ·m_j/ρ_j·(v_j − v_i)·∇²W / ρ_i`.
  - [x] Проверить 2D-нормировки ядер (poly6, spiky, viscosity Laplacian) — сейчас смешаны 2D/3D-формы.
  - [x] Тест с `mass ≠ 1` (стекло 2.5) — поведение не должно ломаться.

### 1.3 Порядок шагов и эмиттер
- **Действия:**
  - [x] Спавн частиц **до** `build_grid`.
  - [x] Реализовать `lifetime`: уменьшение на `dt`, удаление (`swap_remove`).
  - [x] Ограничение шага: `dt ≤ 0.4·h/c_max` (CFL), sub-stepping.
  - [x] Проверка на NaN/Inf в debug-сборке.
  - [x] Использовать параметры материала (`viscosity`, `surface_tension`, `incompressibility`) вместо глобального конфига там, где это задумано; `incompressibility` связать с `B`/γ.

## Этап 6. Новые режимы жидкости (только после этапов 0–4)

### 6.1 Подготовка
- [ ] Trait режима:
  ```rust
  pub trait FluidMode {
      fn step(&mut self, ctx: &mut FluidContext, dt: f32);
  }
  ```
  Общая часть (`FluidContext`): частицы, нейборы, границы, материал, конфиг.
- [ ] Текущий WCSPH оформить как `WcsphMode` (эталон для сравнения).
- [ ] Выбор режима в `config.ron` / материале.

### 6.2 Кандидаты на режимы
| Режим | Идея | Когда полезен |
|-------|------|---------------|
| WCSPH (есть) | слабая сжимаемость, Tait | простота, много частиц |
| PBF | position-based, итерации по ограничениям плотности | стабильность, большие dt |
| DFSPH | дивергенция + плотность без жёсткого `B` | точная несжимаемость |
| PCISPH | предиктор-корректор давления | баланс скорость/точность |
| Вязкие/упругие | XSPH, вязкость по Cross, вязкоупругость | мёд, смола, гель |

Для каждого режима: отдельный модуль в `src/fluids/<mode>/`, свои тесты гидростатики и dam-break, сравнение с WCSPH.
